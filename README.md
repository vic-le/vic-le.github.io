# The Living Archive

A dark, cinematic, monochrome personal and professional portfolio for Vic Le, focused on Library & Information Science, archives, digital collections, and cultural storytelling.

## Publish on GitHub Pages

1. Create a **public** GitHub repository named `the-living-archive`.
2. Upload `index.html`, the other `.html` files, `style.css`, `script.js`, and the `assets` folder to the repository root. You do **not** need to upload `make.py` (it is a local build helper).
3. Open **Settings → Pages → Build and deployment**.
4. Choose **Deploy from a branch**, branch **main**, folder **/(root)**, then save.
5. Your website will be at `https://YOUR-USERNAME.github.io/the-living-archive/` after publishing finishes.

## Customize

- Edit the text in the HTML files with GitHub's pencil/edit control.
- Replace abstract CSS-generated artwork with your own photography. For example, upload `assets/photo1.jpg` and replace an artwork `<div>` with `<img src="assets/photo1.jpg" alt="A descriptive caption" loading="lazy">`; style the image in CSS.
- Add `assets/resume.pdf` only if you're comfortable making that version public, then link it from `about.html`.
- Update the placeholder LinkedIn link in `contact.html` and remove its placeholder notice.
- Project pages contain draft summaries based on your described coursework. Verify and expand these before using them in applications. Obtain permission before publishing group work or personal archival materials.
- Google Fonts are used for typography; a system-font fallback is provided.

## Accessibility

The site includes semantic navigation, keyboard focus styles, a skip link, responsive layouts, and labels for decorative abstract artwork. When adding photography, write meaningful alt text and check contrast.

## Local preview

Open `index.html` in a browser. No build tools or dependencies are needed.
