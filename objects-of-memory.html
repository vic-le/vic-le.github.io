Personal Project / Concept

Objects of Memory

An emerging archival photography project about everyday objects, personal histories, and cultural meaning.

Project Statement

Objects of Memory asks what an ordinary object can tell us about the people who keep it. The proposed series pairs photographs with contextual descriptions, recollections, and carefully recorded provenance.

Sample Description Framework

  • Object title and identifier
  • Creator or owner, when known and approved for publication
  • Date or approximate period
  • Materials, dimensions, and condition
  • Context, story, and source of information
  • Rights, consent, and access notes

Status
