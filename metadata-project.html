LIS Project / Information Organization

Database Design & Metadata

Developing consistent indexing guidance to improve record quality and retrieval.

Project Overview

As part of a collaborative LIS database project, I contributed to initial field rules and helped revise the instructions in response to indexer feedback.

Process

The project involved defining fields, clarifying accepted values, documenting entry conventions, and refining ambiguous guidance for greater consistency.

Reflection

Feedback highlighted the importance of precise language and testing instructions with actual indexers. Collaboration and shared documentation supported iterative improvements.

Skills Demonstrated

Metadata design · Controlled vocabulary · Indexing standards · Quality assurance · Collaborative editing
